# World Explorer refinement

Draft PR #3 only. Keep the child's choice of soil, freshwater or gut while giving each visit a question, three visual field clues, an evidence explanation and a career connection. Aunt Juju introduces the action. Numbered scene controls and equivalent text buttons work in any order; active spots and opened clues are visually distinct. On changing habitats, focus moves to the new field question. Revisited habitats retain this session's opened clues and selected explanation.

Scenes are original SVG teaching illustrations, explicitly not to scale or real sampling results. Opening a hotspot does not identify an organism. Three opened cards unlock explanation choices, not a learning certification. Wrong choices receive specific reasoning and can be revised without penalty. Soil explores decomposition, freshwater explores single-cell movement/feeding, and the gut challenges the assumption that all microbes cause illness or that shape determines harmfulness.

Each closer-look card uses an existing, locally hosted real reference micrograph with credit, instrument, source, reuse terms and image limits. It is explicitly not a specimen taken from the fictional habitat. The connected lab link opens that specimen in free-exploration mode using a validated specimen query parameter; unknown values fall back to the normal lab entry. No new images or image derivatives were created. See public/assets/micrographs/LICENSE.md.

The active route no longer uses the legacy hidden-microbe fixture data, timed discovery effects, queued fact popups, automatic score saves or analytics. Legacy subcomponents/data remain unused by this route for review and recovery. Other modes may still use old data and require separate editorial review. Notes and answers are memory-only, reset on navigation away or reload, and are not sent to a backend. Existing route/parent access controls remain.
