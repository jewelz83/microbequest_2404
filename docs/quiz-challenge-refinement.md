# Quiz Challenge refinement

Draft PR #3 only. Two question sets, Microbe mix and Science detective, each contain three visual questions. An optional fourth virus question requires the existing medium difficulty ceiling. Questions use real, locally hosted reference micrographs already documented in public/assets/micrographs/LICENSE.md. No new image bytes or derivatives. The comparison question deliberately distinguishes displayed photo size from calibrated specimen size.

The active route replaces the legacy question bank, generic generated images, countdowns, fact modals, mastery claims, weighted points, analytics and automatic score writes. Legacy subcomponents remain unused by this route for recovery/review. No backend or production changes. Existing mode, schedule, usage and difficulty controls remain.

A wrong answer provides option-specific reasoning and allows another answer directly, without a continue button. Previously selected wrong choices remain visibly marked Reconsider and cannot be counted twice. Clues and full explanations are optional. A correct answer advances automatically after 1.8 seconds. Opening Tell me more or Explain this cancels automatic advancement and keeps the explanation visible; a next-question control appears only in that intentionally opened explanation. Closing it resumes automatic progression. Pause, new-set confirmation and unmount cancel callbacks; reducer result identity rejects stale callbacks after a later question or reset.

Question headings receive focus on entry and advancement. Answer feedback is an inline live status; there are no modal fact interruptions. Completion provides all explanations for revisiting, shows how many questions needed another choice, and connects to microscope observations/careers. It makes no score, accuracy, knowledge mastery or fabricated achievement claim. Attempts and choices remain in memory and reset on leaving/reloading.

Sources: OpenStax Biology 2e Groups of Protists; OpenStax Microbiology Fungi; CDC About E. coli; specimen source descriptions and microscopy limits in src/pages/microscope-discovery-lab/micrographs.mjs. Science source links and photo credits/instrument/scale limits remain available in the page disclosure. The older local browser fixtures predate this refinement and do not certify this active route. Unit tests cover question balance, misconception feedback, parent ceiling, direct retry, duplicate answers, pause, reset, completion and stale-result rejection. Hosted runtime/visual checks are needed in addition to compilation. Reading-age/science editorial review, remote family feedback, physical devices and broader accessibility review remain before release.
